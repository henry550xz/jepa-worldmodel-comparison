Part 03 / controlled dynamics

Separate learning from the way we measure it.

Billiards makes the dynamics exact, exposing image fitting, spatial access and physical-readout limitations.

03 / A

Known physics, image-only models.

Two balls in a unit 3D box, synchronized XY/XZ/YZ RGB views, three-frame history. Exact physics supplies ground truth. World models train on images; physical-state probes are fitted separately with labels.

Open playback & physics sandboxStandalone simulator

The completed pilot includes a one-episode 2,000-update fit check and a 48-episode 10,000-update learning check for all three objectives. The tiny stage changes data size and is not a controlled duration comparison.

03 / B

A probe-independent check reveals short-horizon learning.

JEPA feature prediction versus latent persistence

Within-model feature MSE divided by persistence MSE; below 1 is better. Ratios do not rank the physical quality of different latent spaces. Six horizons, 16 probe-test episodes, one fixed starting history each.

Evidence: Validated billiards interface diagnostic

Both JEPAs beat persistence at H1–H4. Neither retains that advantage consistently at longer horizons. Stronger MLP probes improve velocity more than position. Physical position readouts stay close to a constant-state baseline.

03 / C

Pixel’s spatial features retain detail that its CLS path does not recover.

Current-image reconstruction: matched decoder capacity

Frozen Pixel encoder; same spatial-decoder parameter count. Full training set, held-out validation images, RGB [0,1]. This reconstructs the input image—it does not predict the future.

Evidence: Validated spatial diagnostic

50×lower validation RGB reconstruction error from patch versus CLS features

CLS: .009322; patches: .000186. The foreground difference is about 83×. This supports a spatial-access bottleneck for this CLS reconstruction path, not proof that CLS has no information.

Patch access did not rescue matched physical readouts. The supervised RGB reference was also limited, so state recovery remains unresolved.

Pixel fitting controls and the failed baseline

At 10k updates, future-image MSE .009202 is about10.7× persistence (.000864). On16 fixed training windows, further end-to-end fitting reaches .003368, decoder-only .007142, and free-code+decoder .003408; persistence is .000652. Those fitting controls are memorization diagnostics, not held-out improvements.

03 / D

Five JEPA conditions: the first scene ablation.

Gaussian and Sparse · 10,000 updates each · seed 0 · matched training schedules. Base, one ball, five balls, paired random colors and paired random backgrounds. Appearance arms share base physical trajectories. This is a partial ablation, not the full ten-condition or multi-seed study.

Takeaway

Use the ablation to characterize sensitivity, not declare a winner.

Short-horizon latent learning is measurable; physical recovery and long-rollout usefulness remain limited. The next architectural question is whether spatial prediction can retain the reconstructable detail while improving future forecasts. That experiment has not been run.
