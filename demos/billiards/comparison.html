Part 01 / outcomes & interfaces

The ranking depends on what we ask the model.

From the original Pixel / Gaussian / Sparse runs to controlled tests of the prediction–readout interface.

01 / A

Start with the task definition.

Official-protocol PushT

Gaussian: 36/50. Sparse: 40/50. These runs establish executable official-protocol baselines. The point difference is not a multi-seed superiority claim.

Our matched physical-goal diagnostic

Pixel / Gaussian / Sparse trained for 115,308 updates each, then evaluated on 124 open-loop episodes and 50 matched candidate/planning banks. Goals are synthetic reachable physical states, not the official coverage task.

Do not compare 36/50 or 40/50 directly with the custom pilot’s final-success counts. Goals, stopping rules and evaluation interfaces differ.

Reaching a goal is not the same as retaining it.

Custom physical goals; 50 matched episodes per arm. Every run executes all ten replans. One training seed.

01 / D

The toy model explains a possibility, not the robotics result.

In a one-dimensional linear bottleneck, Pixel favors predictable observation variance; variance-normalized JEPA favors temporal predictability. When nuisance is more persistent than state, JEPA can choose nuisance too.

360 / 360grid fits selected the analytically predicted coordinate away from ties

At nuisance scale β=4 and correlation .5, future-state MSE is .999 Pixel versus .190 JEPA. At correlation .95, both are about .999: predictability alone does not identify task relevance.

Related evidence that did not establish the same reversal

A separate replacement-predictor study (WMDF) found 0/9 primary H5 reversal cells. Its predictors, panels and metrics differ from the original-checkpoint control above. We retain this negative result and do not pool the protocols.

Takeaway

The objective alone does not explain the decision result.

Static physical probes, rollout accuracy, candidate ranking, and final goal completion must be measured separately. The controlled scorer switch localizes a real interface effect; it does not explain the entire closed-loop gap.
